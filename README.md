# 💳 Форма оплаты с 3D-картой

Интерактивная форма оплаты: банковская карта переворачивается и в реальном времени показывает, что вводит пользователь.

## Возможности

- Номер карты, имя и срок действия сразу появляются на изображении карты
- Номер автоматически разбивается на группы по 4 цифры, буквы отсекаются
- Определение платёжной системы по первой цифре: Visa (4) и Mastercard (5)
- При вводе CCV карта переворачивается на обратную сторону, а клик по ней переворачивает её вручную
- Списки месяцев и годов генерируются скриптом от текущего года

## Стек

HTML, CSS (3D-трансформации, анимации), чистый JavaScript без библиотек.

## Запуск

Склонируйте репозиторий и откройте `index.html` в браузере. Сборка и установка не нужны.
